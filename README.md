# ShopEase 🛒

ShopEase is a responsive e-commerce website built using HTML, CSS, and JavaScript.

## Features

- Product listing with product images
- Search products
- Filter products by category
- Add products to cart
- Increase and decrease product quantity
- Remove products from cart
- Dynamic cart total
- Cart item count
- LocalStorage cart persistence
- Product details modal
- Checkout form
- Order confirmation
- Responsive design for desktop, tablet, and mobile
- Smooth scrolling and interactive UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- DOM Manipulation
